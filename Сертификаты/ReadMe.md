## 📊 Статистика, уровень 2, награда за выдающийся результат

«Токэй кэнтэй» это главный экзамен по статистике в Японии. Его официально признает Японское статистическое общество, а поддержку дают пять государственных ведомств, среди них Министерство внутренних дел и Министерство образования. По сути это полугосударственный экзамен, который сдают студенты и специалисты по всей стране.

Уровень 2 проверяет теорию математической статистики, статистический вывод и проверку гипотез. За свой результат я получил награду за выдающуюся сдачу.

## 🖥 SAS Base Programming

SAS это система для статистического анализа. Сертификат выдает сама компания SAS Institute, то есть разработчик программы, поэтому это самый официальный экзамен по этому продукту.

SAS хорошо известен в медицинской статистике, где на нем делают анализ выживаемости и другие расчеты. Но применяют его гораздо шире. Банки, страховые компании и производство ведут на SAS регулярную отчетность, проверяют качество данных и считают показатели. В работе аналитика данных SAS закрывает те же задачи, что SQL и Python, то есть подготовку данных, расчет метрик и статистические тесты. Этот опыт помогает мне быстро осваивать любые инструменты такого типа.
