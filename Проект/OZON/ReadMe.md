# 📊 Кейс. Принятие решения по результатам АБ-теста

## 1️⃣ Допущение о вариантах

В условии не указано прямо, какой из вариантов соответствует пониженной цене. Вывод сделан на основе двух признаков. Во-первых, по общепринятому порядку именования вариант А это контроль с текущей ценой, а вариант Б это эксперимент с пониженной ценой. Во-вторых, в варианте Б доля начавших заполнение формы выше, 32% против 30% в А, что согласуется с гипотезой о снижении цены.

## 2️⃣ Скрытая конверсия воронки

Воронка состоит из трёх стадий, а именно визит, начало заполнения и завершение. Из этого выводятся три показателя конверсии.

- CR1, это конверсия из визита в начало заполнения
- CR2, это конверсия из начала заполнения в завершение
- CRtot, это конверсия из визита в завершение

CR1 и CRtot видны напрямую в исходных данных теста. В варианте А CR1 равен 30%, в варианте Б 32%, то есть рост на 2 процентных пункта. При этом CRtot в обоих вариантах одинаков и равен 18%. Показатель CR2 в исходных данных не указан напрямую, поэтому он вычислен отдельно.

```
CR2 (А) = 22909 / 37765 ≈ 60,66%
CR2 (Б) = 23017 / 40029 ≈ 57,50%
```

В варианте Б из числа тех, кто начал заполнение, до завершения доходит меньшая доля, разница составляет минус 3,16 процентного пункта. Несмотря на рост CR1, итоговый показатель CRtot не изменился. Значит, внутри воронки появился дополнительный отвал пользователей, и он виден только через показатель CR2.

## 3️⃣ Проверка статистической значимости

Для каждой из трёх конверсий проверялась гипотеза о равенстве долей между вариантами А и Б, двухвыборочным z-тестом для пропорций на уровне значимости 0,05. Критическое значение равно 1,96.

| Тест | Вывод |
|---|---|
| CR1, визит → начало | гипотеза о равенстве отвергается |
| CR2, начало → завершение | гипотеза о равенстве отвергается |
| CRtot, визит → завершение | гипотеза о равенстве не отвергается |

Рост CR1 и падение CR2 в варианте Б оба статистически значимы, тогда как изменение CRtot статистически не значимо. Это значит, что реальные изменения происходят внутри воронки, а на её выходе они взаимно компенсируют друг друга.

## 4️⃣ Интерпретация

Форма заполнения не менялась, поэтому дело не в её удобстве. Дополнительный отвал пользователей в варианте Б происходит именно на стадии заполнения формы. Скорее всего, пониженная цена привлекает пользователей, которые при виде остальных условий продукта отказываются от продолжения. Поэтому рост числа начавших заполнение в варианте Б не превращается в прирост завершивших, а значит, вариант Б не даёт прибавки к активной базе клиентов. Само по себе снижение цены обслуживания не даёт статистически значимого эффекта на итоговое привлечение клиентов.

## 5️⃣ Решение и оценка по ключевым показателям

Главная метрика это активная база, то есть число завершивших. Поскольку это число фактически не изменилось, вариант Б по этой метрике ничего не даёт.

Защитная метрика это удельная доходность. Вариант Б уменьшает плату за обслуживание, а транзакционный доход эту потерю не покрывает, так как число завершивших не выросло. При этом операционные расходы растут из-за увеличения числа незавершённых заявок. Значит, защитная метрика тоже нарушается.

**Итоговое решение.** По обеим метрикам вариант Б проигрывает варианту А. Поэтому выбор сделан в пользу варианта А, без снижения цены обслуживания.
