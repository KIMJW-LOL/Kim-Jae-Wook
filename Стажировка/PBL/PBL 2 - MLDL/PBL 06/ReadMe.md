## 📌 Ситуация

Недавно в модель GPT-4 от OpenAI добавили функцию вызова функций, которая позволяет во время диалога передавать запрос пользователя на обработку внешней функции. Эта функция даёт возможность выполнять чёткие задачи, такие как вычисления, преобразование дат и поиск, на уровне кода и включать в диалог только сам результат, что заметно повышает точность и полезность чат-бота. С опорой на эту функцию нужно реализовать AI агента, который сам обрабатывает запросы на преобразование формата даты и на сложение чисел. Когда пользователь обращается на обычном языке, модель должна сама выбирать нужную функцию, вызывать её и затем отвечать пользователю снова на обычном языке.

## 🎯 Цели обучения

✅ Понимать и уметь применять Chat API модели GPT-4 от OpenAI
✅ Уметь через функцию вызова функций регистрировать собственные функции пользователя и проектировать поток их автоматического вызова
✅ Уметь реализовать на Python весь поток от вопроса пользователя до выполнения функции и финального ответа

## 📝 Что нужно сделать

- Реализовать на Python AI ассистента на основе функций, используя API GPT-4 от OpenAI
- Определить и зарегистрировать две собственные функции, а именно convert_date_format, которая переводит строку с датой в другой формат, и add_numbers, которая складывает два числа
- Настроить так, чтобы модель GPT сама выбирала и вызывала подходящую функцию на основе запроса пользователя на обычном языке
- Поток ответа модели должен быть таким. Сначала ввод пользователя и решение модели о вызове функции. Затем функция, которую запросила модель, выполняется напрямую. Далее результат выполнения передаётся обратно модели. И наконец формируется финальный ответ на обычном языке

Условия реализации

- Использовать библиотеку OpenAI для Python
- Оформить работу через класс OpenAIAgent
- Включить логику, которая определяет, нужен ли вызов функции, и обрабатывает результат выполнения
- Код должен быть реально рабочим, при этом ключ API нельзя вписывать прямо в код, для него нужна отдельная переменная

## 💡 Подсказки к решению

- Настройка окружения для API. Импортировать модули openai и OpenAI, задать ключ API через переменную, при реальном запуске рекомендуется использовать переменные окружения
- Определение функций. convert_date_format(date_str, current_format, target_format) и add_numbers(x, y), а также JSON схема для функции вызова функций для обеих функций
- Реализация класса агента. Класс OpenAIAgent, метод chat, который принимает ввод пользователя и ведёт диалог, а также вспомогательные методы вроде call_openai и handle_function_call
- Обработка потока вызова функции. Если в ответе модели есть function_call, функция выполняется, а результат добавляется в messages для второго запроса и получения финального ответа на обычном языке
- Тестирование, например на запросах "переведи 2024-12-25 в формат 2024년 12월 25일" или "сколько будет 23.5 плюс 3.1"
