## 📌 Ситуация

Дана задача выполнить базовую обработку данных и разведочный анализ данных (EDA) по данным диагностики диабета.

## 🎯 Цели обучения

✅ Изучить способы обработки пропусков и выбросов
✅ Умение выполнять нормализацию с помощью MinMaxScaler
✅ Умение выполнять EDA с помощью Pandas

## 📝 Что нужно сделать

Данные это файл diabetes.csv, известный как набор данных Pima Indians Diabetes

Требования

- Обработка пропусков. В столбцах Glucose, BloodPressure, SkinThickness, Insulin и BMI значение 0 считается пропуском и заменяется средним
- Обработка выбросов. В столбцах SkinThickness и Insulin верхний 1 процент значений считается выбросом и заменяется средним
- Нормализация. Столбец Age нормализуется в диапазон от 0 до 1 с помощью MinMaxScaler
- EDA. Вывести число пропусков в каждом столбце, вывести средний уровень глюкозы по каждой группе Outcome, вывести первые пять строк таблицы после обработки

## 💡 Подсказки к решению

- Загрузить и обработать данные через Pandas
- Использовать replace, fillna, quantile и apply
- Выполнить нормализацию через MinMaxScaler
- Вывести сводную статистику через groupby и isnull
