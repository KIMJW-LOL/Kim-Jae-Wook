## 📌 Ситуация

Нужно спроектировать модель глубокого обучения для бинарной классификации, которая по данным о клиентах предсказывает, уйдёт клиент или нет.

## 🎯 Цели обучения

✅ Умение строить модель глубокого обучения для бинарной классификации
✅ Умение справляться с дисбалансом классов и выполнять нормализацию
✅ Повысить умение оценивать качество модели классификации

## 📝 Что нужно сделать

Данные это файл customer_data_balanced.csv

Требования

- Обработка данных. Столбец ContractType кодируется через One Hot кодирование, данные нормализуются через StandardScaler
- Модель. Многослойный персептрон на основе Dense слоёв, включая Dropout, с выходом через сигмоиду и функцией потерь Binary Crossentropy
- Оценка. Вывод значений Accuracy, F1-Score, матрицы ошибок и отчёта classification_report

## 💡 Подсказки к решению

- Построить модель в keras по схеме Input, затем Dense, затем Dropout, затем снова Dense
- Посчитать показатели оценки через metrics из sklearn
